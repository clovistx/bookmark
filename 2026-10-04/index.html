Seis bibliotecas que fazem a UI parecer de produto pago — gosto sem virar designer

@kasuncfdo reuniu toolcraft, pinui, solace ui, easyui, pace ui e feral ui: kits e blocos para jogar no Cursor ou no Claude e sair com tela que parece cara.

Noite · @kasuncfdo

A lista é direta — starter e componentes open-source pensados para vibecoding, do kit de design custom ao bloco de marketing e ao componente animado em React, Tailwind e Framer Motion. O recado do post é que gosto e bookmark valem mais do que diploma de UI: você dropa a lib no agent e deixa cozinhar. toolcraft

toolcraft: starter kit open-source para apps de design custom com AI

O toolcraft entrega um ponto de partida visual completo quando o agent precisa de um sistema de UI coerente, não só de um botão isolado. Vale clonar ou apontar o Cursor para o site e pedir uma tela no mesmo idioma visual.

toolcraft.sh · @alex_barashkov

pinui

pinui: componentes com cara GenZ para quem vibecoda

O pinui mira energia e menos cara enterprise — útil quando a interface precisa parecer viva sem passar por um time de design. No fluxo com Claude, serve como referência de tom visual para o agent copiar.

pinui.xyz · @RachitThakur146

solace ui

solace ui: blocos prontos para páginas de marketing

A solace ui acelera landing e seções de produto com blocos já montados, em vez de começar o hero no vazio. Quem joga marketing page no Cursor ganha um atalho de estrutura e ritmo tipográfico.

solaceui.com · @harshitlog

easyui

easyui: componentes animados em React, Tailwind e Framer Motion

O easyui empilha motion sem reinventar easing: componentes animados no stack React + Tailwind + Framer Motion. É o tipo de lib que o agent encaixa rápido quando a tela precisa de microinteração sem um motion designer na sala.

easyui.site · @surajmaurya_m
