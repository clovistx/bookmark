O Opus 5.5 construiu um mundo inteiro dentro de uma redoma de vidro, e dá para espremer chuva das nuvens

O Weatherglass é um artifact do Claude em que nuvens, vento, neblina, sol e estações respondem ao mouse, e o perfil oficial do three.js fez questão de espalhar.

Domingo · @threejs · @LexnLin

Leon Lin (@LexnLin), que se apresenta na bio como estudante do ensino médio dedicado a creative AI, publicou um vídeo do Weatherglass com uma legenda curta: o Opus 5.5 construiu um pequeno mundo numa caixa de vidro. A cena é uma paisagem em miniatura, com montanhas, cachoeira, lago e o corte das camadas de terra visível pela lateral da redoma. A interação é o que impressiona: dá para agarrar uma nuvem e espremer a chuva, sacudi-la para soltar raios, desenhar vento com um pincel, espalhar neblina, arrastar o sol e virar as estações, com ciclo de dia e noite rodando sozinho.

O perfil oficial do three.js (@threejs) repostou o projeto no domingo só com um emoji de nuvem, o que diz bastante sobre o nível do resultado. O link aponta para um artifact público no claude.ai, então qualquer pessoa abre e brinca no navegador, sem instalar nada. O exercício que vale a pena é abrir o Weatherglass, testar cada gesto e depois pedir ao teu modelo favorito uma cena interativa do mesmo tamanho, para medir na prática a distância entre o que ele entrega e o que o Opus 5.5 entregou aqui.

Para entender e para enfeitar

LLMs · WebGPU
LLMs · explainer

O Transformer Explainer roda um GPT-2 no navegador e mostra cada etapa até o próximo token

O perfil Tech with Mak (@techNmak) recomendou o Transformer Explainer, projeto do Polo Club da Georgia Tech que baixa um GPT-2 de cerca de 600 MB direto no navegador. A pessoa digita uma frase e acompanha o caminho inteiro, da tokenization aos embeddings, dos vetores Q, K e V à attention, passando pelo MLP até os logits e as probabilidades do próximo token. Dá para abrir os mapas de attention de cada head, inspecionar os valores intermediários e mexer em temperature, top-k e top-p para ver como a geração muda. Para quem conhece transformer só como caixinhas ligadas por setas, é o jeito mais rápido de ver a máquina funcionando, e serve muito bem para explicar o assunto para o time.

WebGPU · open source

O Shaders abriu o código de mais de 200 efeitos WebGPU que funcionam como componentes

O Shaders (@npm_i_shaders), biblioteca usada por mais de 16 mil design engineers segundo o próprio README, tornou open source sob licença MIT o engine, os componentes e os bindings para React, Vue, Svelte, Solid e JavaScript puro. Cada efeito, de gradientes e noise a vidro, metal, distorções e cursor trails, entra como um componente dentro de um <Shader>, e as camadas são combinadas na GPU. O editor visual do shaders.com exporta o código para qualquer framework de graça, e o plano Pro fica só com os presets prontos, as seções de site e o render de vídeo sem marca d'água. O pulo do gato para quem trabalha com agents é que o projeto já traz um skill, um MCP server instalado com npx shaders@latest install-mcp e um llms.txt, então dá para pedir ao Cursor ou ao Claude Code um hero com shader e ver o que sai.

O Mac por dentro

macOS · Grok Bot
macOS · disco

O MacSpace explica o que é o System Data e apaga os modelos do Apple Intelligence

O perfil Snow Brave (@Sn0wbrave) contou a história de um desenvolvedor que, sem entender por que o System Data ocupava tanto espaço no Mac, passou um mês investigando e publicou o MacSpace, gratuito e open source sob licença MIT. O app quebra o System Data em caches, logs, relatórios, assets do sistema e histórico de versões de documentos, e o botão principal só apaga o que é seguro, como caches de apps fechados e relatórios de crash com mais de sete dias. Um switch desliga o Apple Intelligence trocando o idioma da Siri e depois remove os modelos guardados em disco, que podem chegar a uns 12 GB, e há ainda catorze switches de debloat para analytics e coleta de dados em background. O aviso importante do README é que, com a sincronização da Siri pelo iCloud ligada, a troca de idioma chega também ao iPhone e ao iPad; quem quiser testar instala com brew install --cask 1architect/macspace/macspace e começa pela tela de System Data, que só mostra antes de apagar.

Grok Bot · Apple

Sem connectors da Apple, Kevin Logan mandou o Grok Bot usar CLIs no Mac, e diz que funciona

Kevin Logan (@Kevin_Logan) postou o atalho que encontrou para a falta de connectors da Apple no Grok Bot: uma lista que associa cada app a um CLI rodando no Mac, como remindctl para o Reminders, imsg para o Messages, memo para o Notes e apple-calendar, apple-contacts, apple-mail, apple-maps e apple-phone para o resto. Fotos ficam com o Spotlight e as ferramentas do Photos, e o Find My só é aberto pela interface gráfica quando ele pede. Segundo ele, basta dizer uma vez ao bot para usar essas ferramentas, e a partir daí tudo funciona. O post não diz de onde vem cada CLI, então o caminho prudente é conferir a origem de cada um antes de instalar e começar por algo inofensivo, como pedir ao Grok Bot para criar um lembrete pelo remindctl.
