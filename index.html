Grok Bot · HarnessRouter · multi-agent

Brian Roemmele faz do Grok Bot o coordenador e manda o trabalho pesado para o harness certo

Num texto longo publicado no sábado, ele descreve como combina o Grok Bot com o HarnessRouter, um projeto open source que dá uma única API para duas dúzias de agent harnesses.

Sábado · @BrianRoemmele · HarnessRouter Community Edition

Brian Roemmele (@BrianRoemmele) parte de uma crítica simples: a maioria trata sistemas multi-agent como um robô gigante ou como uma pilha de ferramentas que não conversam entre si. O arranjo que ele adotou mantém um coordenador de longa duração, o Grok Bot, com memória, rotinas e computador próprio, como a única interface da conversa. O Bot quebra o pedido em etapas e delega cada uma ao harness mais adequado por meio do HarnessRouter, que implementa o Unified Harness Protocol (UHP) e expõe uma API compatível com a Responses da OpenAI para dirigir Codex, Claude Code, Hermes, DeepSeek Harness, Pi, Grok Build e outros, cada um no seu runtime nativo.

No uso pessoal, o HarnessRouter roda self-hosted num docker run numa máquina dele: pesquisa e análise de contexto longo vão para o DeepSeek Harness ou o Claude Code, refactor pesado vai para o Codex ou o Pi, e as rotinas recorrentes, como triagem de inbox e resumos de status, continuam no próprio Grok Bot. Trocar de harness ou de modelo por custo ou qualidade passa a ser uma mudança de metadata, não uma reescrita. Para clientes corporativos, o argumento é controle de dados: a Community Edition roda na VPC ou no servidor do cliente, e as chaves, os workspaces e os arquivos não saem dali. O repositório, sob licença Apache-2.0, já passa de 3.500 estrelas no GitHub, e o próprio post avisa que é a primeira de duas partes.

O primeiro dia de um MacBook novo

@soltwagner · apps nativos para macOS
macOS · indie apps · @soltwagner

Solt Wagner perguntou o que instalar no MacBook Pro novo e respondeu com cinco apps de desenvolvedores independentes

Na madrugada de sábado, Solt Wagner (@soltwagner) postou duas fotos do MacBook Pro recém-chegado e perguntou aos seguidores o que deveria instalar. A pergunta passou de 390 mil visualizações e rendeu mais de 200 respostas e quase 600 bookmarks, o que diz bastante sobre o apetite por boas recomendações de software para Mac.

Horas depois, ele mesmo publicou a lista do que entrou primeiro na máquina: um histórico de clipboard, um gravador de tela que também edita vídeo, um segundo Dock com widgets ao vivo, gestos de toque na lateral do notebook e um painel que reúne a receita de várias plataformas de pagamento. Os cinco estão no Radar abaixo, e quase todos têm cara de produto pequeno e caprichado, do tipo que resolve um incômodo diário sem pedir assinatura cara.

Radar

a lista do Mac novo e uma biblioteca de animação
clipboard · Supaste

O Supaste guarda tudo o que você copia numa timeline pesquisável

O app é local-first e salva textos, links, imagens, arquivos, trechos de código, cores e screenshots num histórico que fica no próprio Mac. É o primeiro item da lista do Solt, e o tipo de ferramenta que se paga na primeira vez que você precisa de algo copiado ontem.

supaste.com

vídeo · Screen Movie

O Screen Movie grava a tela e já entrega o vídeo editado

Além de capturar tela e screenshots, ele anima textos, imagens e legendas, adiciona música e exporta vídeos de produto prontos para publicar. Para quem grava demos com frequência, a proposta é eliminar a ida e volta entre o gravador e o editor.

screen.movie

widgets · CoolDock

O CoolDock acrescenta um segundo Dock, este cheio de widgets ao vivo

A barra extra mostra música, tarefas, eventos do calendário, clima, busca, estatísticas do sistema e ações rápidas sem abrir janela nenhuma. Ela ocupa o espaço que o Dock tradicional deixa ocioso na maior parte do dia.

cooldock.app

gestos · Shortap

O Shortap transforma toques na lateral do MacBook em atalhos

Um, dois ou três toques no lado esquerdo ou direito do notebook disparam mais de 50 ações ou qualquer atalho do app Atalhos da Apple. O pagamento é único, a partir de US$ 5, o que torna fácil experimentar sem compromisso.

shortap.app

receita · Revone

O Revone junta numa tela a receita de Stripe, Gumroad, Paddle e companhia

O app nativo acompanha vendas em Stripe, Gumroad, Lemon Squeezy, Polar, Paddle e RevenueCat, com dashboards, pedidos, assinantes, widgets e números na barra de menu. Para quem vende software em mais de uma plataforma, ele substitui a ronda diária por vários painéis.

revone.app

UI · open source · @saurra3h

O beUI oferece componentes animados gratuitos para React e React Native

A biblioteca, que Saurabh (@saurra3h) divulgou com bom humor, reúne componentes open source feitos com Motion, Tailwind CSS e Reanimated para React, Next.js e React Native. Dá para copiar o código-fonte direto ou instalar cada peça pela CLI, o que facilita testar um componente sem adotar o pacote inteiro.

Hora do Hands-on

três testes de dez minutos · pro domingo
teste 1 · HarnessRouter

Um HarnessRouter local e uma tarefa delegada ao Claude Code

Suba a Community Edition com o docker run do README, cadastre uma chave de provider no console e gere uma API key. Depois mande uma única chamada para o endpoint Responses com o harness_id do Claude Code e uma tarefa pequena, como resumir um repositório de teste, e veja o que volta.

teste 2 · beUI

Um componente animado num projeto Next.js de rascunho

Escolha um componente no site do beUI, instale pela CLI num projeto Next.js descartável e abra no navegador. Repare em quanto código veio junto e se a animação continua suave quando você reduz a janela para o tamanho de um celular.

teste 3 · Supaste

Uma manhã de trabalho com o histórico de clipboard ligado

Instale o Supaste e deixe ele rodando enquanto trabalha normalmente por algumas horas. No fim, procure na timeline um link ou trecho de código copiado lá no começo e avalie se a busca encontra o que você queria sem esforço.
