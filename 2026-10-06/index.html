A SemiAnalysis mediu o limite de cada plano de AI, e a Anthropic sai entregando cinco vezes mais que a OpenAI

Andrew Megalaa, Max Kan e Dylan Patel cronometraram o medidor de uso de nove provedores, de Anthropic e OpenAI a Cursor, Cognition e os labs chineses, para descobrir quanto de API cada assinatura realmente compra.

Segunda · @SemiAnalysis_

O método é engenhoso. Em vez de confiar no marketing de “5x mais uso”, a equipe dispara chamadas que isolam um tipo de token por vez (input, cache write, cache read e output) e conta quantos tokens cabem entre cada movimento dos medidores de 5 horas e de 7 dias. Com isso, cada combinação de plano, modelo e workload vira um valor equivalente de API. No tier intermediário, que as duas empresas vendem como daily driver, o Opus 5.5 num plano Claude rende cerca de cinco vezes o valor do GPT 6.1 Sol num plano da OpenAI.

O contexto explica por que as labs vivem mexendo nos limites. Pelas contas da SemiAnalysis, as assinaturas são só 10% da receita da Anthropic, mas ocupam mais de 40% do compute de inference. A OpenAI acaba de cortar pela metade o valor do plano de US$ 200 (quem assinou antes mantém o limite antigo até 29 de outubro) e lançou um tier de US$ 500. No meio dos testes, a equipe ainda flagrou um A/B test “extremamente pequeno” de limites numa das contas, prova de que os provedores mudam a régua em silêncio.

Se você paga mais de uma assinatura para rodar agents, o texto é um bom motivo para revisar onde cada workload está rodando. O artigo completo é pago, mas a parte aberta já traz o método e os números principais.

Grok Bot · guia

Como contratar o primeiro Grok Bot como se fosse um funcionário, com período de experiência e tudo

@distortgeekin escreveu um guia longo que trata o Bot como contratação, não como prompt: uma frase de ownership que continue verdadeira no mês seguinte, um primeiro job chato e reversível, um dry run em texto antes de qualquer ação e três runs de probation antes de soltar a rédea. A régua de permissão é a reversibilidade, não a importância da tarefa, então pesquisar, rascunhar e organizar vão sem pedir, enquanto enviar, publicar, comprar ou apagar sempre voltam para você. O guia também lembra que Bots da mesma conta dividem o mesmo computador, os mesmos arquivos e os mesmos logins, de modo que o nome separado é só uma fronteira visual. A dica que fica é escrever, antes do primeiro run, a linha do que o Bot deve fazer quando estiver em dúvida.

A tier list de AI orchestrators de outubro deixa o T3 Code Nightly sozinho no topo

Guilherme Vasques (@Ga_Vasques) atualizou o ranking que monta a partir do uso diário, e o T3 Code Nightly subiu para SS por estar, segundo o post, liso, intuitivo e fácil de acompanhar. pstack · skills

O pstack 0.15.9 ganha um /correct que transforma a bronca repetida no agent em arquitetura

@poteto lançou a versão 0.15.9 do pstack, o plugin de workflows de engenharia que vive no repositório de plugins da Cursor, com uma skill nova chamada /correct. Quando você corrige o agent pelo mesmo erro várias vezes, ela encontra o padrão e resolve com arquitetura, types e checks, em vez de mais uma instrução no prompt. A ideia retoma um post anterior do perfil, que ordena as saídas por valor: eliminar o problema pela arquitetura, depois virar lint ou teste no CI, depois skill ou regra, e só por último code review humano. A release ainda traz um /architect com instruções de arquitetura agent-friendly, um /benchmark-checklist baseado no checklist do Brendan Gregg e um prompt pronto para o Grok Bot montar um Project agent que vasculha os commits antigos e devolve um plano de refactor com dados reais.

Sitegeist é um browser agent open-source que mora na side panel do Chrome e usa as tuas keys

A dica veio de uma resposta do @grok. O Sitegeist, criado por Mario Zechner, é uma extensão gratuita para Chrome e Edge que navega por sites, faz scraping, preenche formulários e automatiza tarefas repetitivas guiado pelo chat, sempre com as tuas próprias API keys. O projeto se apresenta como colaboração, não “autonomy theater”, e o repositório original já passa de 880 stars. O fork do 0xSero adiciona background tabs e bridges para que coding agents controlem o browser, o que abre espaço para plugar o Sitegeist num harness de agents e mandar uma tarefa de coleta que hoje você faz na mão.
