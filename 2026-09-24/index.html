Rollouts: o Cursor passa a vigiar o deploy por você

A ferramenta escreve um plano de monitoramento, acompanha a mudança em produção e só libera o tráfego depois de verificar que a regressão não escapou.

Noite · @cursor_ai

O Cursor apresentou os Rollouts como camada de verificação em cima do deploy: em vez de torcer no pós-merge, o sistema observa métricas e comportamento enquanto a mudança sobe. Para quem já vive de agent + PR em série, o ganho é pegar a quebra antes do usuário — e não no Slack das 23h. Vale abrir o anúncio e encaixar no fluxo de release do teu time.

Prompt longo pra baratear o agent harness sem perder qualidade

@ericzakariasson publicou um roteiro denso — nascido do que o time do Cursor aprendeu em produção — pra cortar custo ponderado de tokens por tarefa concluída. A ordem é clara: mapear o harness, medir baseline por tipo de billing, offload de tools raros, layout de cache e só então propor troca de modelo. Se o teu agente está caro demais por rodada, cola o prompt e pede o relatório com diff do system prompt.
